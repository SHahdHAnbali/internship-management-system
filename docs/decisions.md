## B. Assumptions (reasonable defaults, change if wrong)

1. **Arabic is the default UI language** (`<html lang="ar" dir="rtl">`), with English as the second language. The PDF names both and is written in Arabic.
2. All timestamps are stored in UTC. Assignment start and end are calendar dates. The company time zone is assumed to be the operating zone for reminders (*confirmed by the owner, 2026-11-10, AD-62:* Asia/Hebron).
3. The API issues its own session cookie after verifying a Google sign-in or a trainee email code, so both identity types share one authorization model (AD-12). The session idle timeout defaults to 8 hours in the ASP.NET API (`Authentication:Session:IdleTimeoutMinutes`). The PDF does not specify one. The Workers API follows AD-44 (7 days idle, 30 days absolute).
4. API routes are served under `/api`. The public certificate page is an SPA route `/c/:code`, matching the PDF example `training.company.com/c/X7K2P9`.
5. The "status" values of `TrainingApplication` and `Assignment` in [domain-model.md](domain-model.md) are proposals. The PDF only fixes `MentorRequest` statuses (Pending/Approved/Rejected).
